# PocketPGP 0.1.4

Tiny release, delivered in-app.

## Added

- **Version shown in Settings.** The app version (and license) now appears
  in the Settings dialog footer, so you always know which build you're on.

## Install

Click **Update now** in the notification banner, or Settings → *Check for
updates now*. Signature-verified, installed, relaunch automatic.

| File | What |
|---|---|
| `PocketPGP_0.1.4_x64-setup.exe` | Installer — per-user, no admin prompt |
| `PocketPGP-0.1.4-win64-portable.zip` | Portable build — one exe |
