# PGPBench 0.2.1

Visual polish release, delivered in-app: updates the Windows application icon to match the diagonal key logo inside the app.

## Changed

- Replaced the application icon (`icon.ico` and bundled icon assets) with the diagonal key on the indigo-to-purple rounded square used in the app header, and aligned the in-app header SVG to match.
- Updated README screenshots, animated demo GIF, and added a GitHub downloads badge.

## Install

Click **Update now** in the notification banner, or Settings, then *Check for updates now*. Signature-verified, installed, relaunch automatic.

| File | What |
|---|---|
| `PGPBench_0.2.1_x64-setup.exe` | Installer, per-user, no admin prompt |
| `PGPBench-0.2.1-win64-portable.zip` | Portable build, one exe |
