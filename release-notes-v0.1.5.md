# PocketPGP 0.1.5

Text-only release, delivered in-app: light copy editing across the app UI, plus the README and release notes. No behavior changes.

## Changed

- Replaced em dashes with plain punctuation in user-facing text (UI hints, README, release notes) for a cleaner, more accessible read.
- The README now opens with an animated demo of the core flow: paste a message, unlock with your passphrase, read the verified plaintext, then compose a reply and encrypt it.

## Install

Click **Update now** in the notification banner, or Settings, then *Check for updates now*. Signature-verified, installed, relaunch automatic.

| File | What |
|---|---|
| `PocketPGP_0.1.5_x64-setup.exe` | Installer, per-user, no admin prompt |
| `PocketPGP-0.1.5-win64-portable.zip` | Portable build, one exe |
